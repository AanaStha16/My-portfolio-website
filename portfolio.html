Academic & Research Portfolio

A selection of my recent projects focusing on machine learning, computational data processing, and software engineering.

Hemavision AI

For my Computer Science capstone project, I am the Model Lead on a team developing an Interpretable Automated Diagnostic Framework for Blood Pathology. We utilize vision transformers and deep learning to build a robust AI Hematopathologist tool.

LiDAR Canopy Analysis

Working with the Digital Forestry Lab, I developed a Python-based segmentation tool for 3D point cloud data. By implementing K-Means clustering algorithms using laspy and scikit-learn, I successfully automated the resolution of tree canopy splitting errors.

Astronomy Visualizer

I built a graphical user interface in Python using Tkinter and Matplotlib that pulls data directly from NASA Exoplanet APIs. The tool filters complex celestial datasets and renders interactive 3D orbital simulations and 2D scatter plots.
